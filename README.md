# 학습 허브 대시보드

학점은행제(학은제) + SQLD 통합 학습 체크리스트 대시보드입니다.

## GitHub Pages로 보기
1. 이 저장소를 GitHub에 올립니다 (`index.html`이 루트에 있어야 합니다).
2. 저장소 **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`로 두고, 브랜치를 `main`(폴더 `/root`)으로 선택 후 저장합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 주소로 접속하면 대시보드가 열립니다.

## 구성
- **전체** 탭: 날짜별 통합 할 일 (지난 미완료는 맨 위 "밀린 할 일"에 유지)
- **SQLD** 탭: 챕터 진행표 + 날짜별
- **학은제** 탭: 과목별 진행 하위 탭
- **완료** 탭: 실제 완료일 기준 학습 이력

## 저장 방식 안내
- 체크 기록은 **브라우저(localStorage)**에 저장됩니다. 같은 브라우저로 다시 열면 유지되지만, **기기 간 동기화는 되지 않습니다.**
- 기기 간 자동 동기화가 필요하면 claude.ai에 게시된 온라인 버전을 사용하세요.
