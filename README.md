# 학습 허브 (가려닝 · 학은제 + SQLD)

학점은행제(8과목 × 26차시 = 208차시)와 SQLD(107강)를 하루 단위로 통합 관리하는 단일 HTML 학습 체크리스트입니다. 별도 빌드·서버 없이 `index.html` 하나로 동작합니다.

## 깃허브 연동 (GitHub Pages 배포)

1. 새 저장소를 만들고 `index.html`과 `README.md`를 업로드합니다. (이 파일명 그대로 올리면 됩니다.)
2. 저장소 **Settings → Pages** 로 이동합니다.
3. **Source** 를 `Deploy from a branch`, **Branch** 를 `main` / `/ (root)` 로 선택하고 저장합니다.
4. 잠시 후 `https://<깃허브아이디>.github.io/<저장소명>/` 주소로 열립니다.

> 파일명이 반드시 `index.html` 이어야 루트 주소에서 바로 열립니다.

## 주요 기능

- **전체 / SQLD / 학은제 / 완료** 탭. 전체 탭은 오늘부터의 날짜별 통합 체크리스트.
- 지난 미완료 항목은 상단 **"밀린 할 일"** 에 모아 표시(완료하면 완료 탭으로 이동).
- **완료 탭**은 날짜 없이 **과목별(SQLD·각 학은제 과목)로 묶어** 완료 강의를 보여줍니다.
- SQLD 챕터 진행표, 학은제 과목별 진행률, D-day(SQLD·중간·기말) 표시.
- 다크 모드 자동 대응.

## 진행 기록 저장 방식

- 체크 기록은 **브라우저(localStorage)** 에 저장됩니다. 같은 브라우저로 다시 열면 이어집니다.
- 처음 열면 현재 진행률(SQLD 1~19, 네트워크1 1~4)이 자동으로 체크된 상태로 시작합니다.
- 상단 **☁ 배지**로 저장 상태를 표시합니다. GitHub Pages에서는 "이 브라우저에만 저장"으로 동작하며, 폰·PC 등 **기기가 바뀌면 각 기기에서 따로 체크**됩니다.

## 수정 방법

일정·강의 내용은 `index.html` 안의 `const DATA = { ... }` 객체에 들어 있습니다. 날짜별 `sq`(SQLD)·`hak`(학은제) 배열을 편집하면 되고, 처음 열었을 때 체크될 항목은 `const SEED = [ ... ]` 에서 조정합니다.
