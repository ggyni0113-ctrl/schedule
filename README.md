# 학습일정

학점은행제(학은제) + SQLD 통합 학습 체크리스트 대시보드입니다. (파스텔 테마)

## GitHub Pages로 보기
1. 이 저장소를 GitHub에 올립니다 (`index.html`이 저장소 루트에 있어야 합니다).
2. **Settings → Pages**로 이동합니다.
3. **Source**를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`로 지정 후 저장합니다.
4. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

## 탭 구성
- **전체**: 날짜별 통합 할 일. 지난 미완료는 맨 위 "밀린 할 일"에 그대로 유지됩니다.
- **SQLD**: 상단 챕터 진행표(SQL 활용 · 관리구문 · CBT 기출) + 날짜별.
- **학은제**: 상단 과목별 진행 하위 탭.
- **완료**: 실제 완료한 날짜 기준 학습 이력.

## 일정 규칙
### 학은제
- 하루 **2과목**(각 과목 연속 2차시) = 4강씩 진행합니다.
- 모든 항목은 **미완료 상태로 시작**합니다. 수강한 것부터 직접 체크하면 완료일 기준으로 "완료" 탭에 기록됩니다.
- **11/2부터 5·6차시**(네트워크1·데이터베이스)로 시작해 과목을 2개씩 돌며 마감일에 맞춰 진행합니다.

### SQLD (시험 11/14)
- 강의 수강은 제외했습니다.
- **11/2~11/4: 이론 정리** — SQL 활용(서브쿼리·윈도우함수·계층형·PIVOT·정규표현식) → 관리구문(DML·TCL·DDL·제약조건·DCL).
- **11/5~11/13: CBT 기출문제** 위주 풀이 + 오답노트, 11/13 총정리.
- 이론·기출 참고: **https://sqldyangpa.com/** (무료 · 45~60회 기출 복원 800문항 · CBT 모의고사)

## 저장 방식 안내
- 체크 기록은 **브라우저(localStorage)**에 저장됩니다. 같은 브라우저로 다시 열면 유지되지만 **기기 간 동기화는 되지 않습니다.**
- 처음 열면 과거 수강 완료분(1~4차시)이 자동으로 완료 처리되어 "완료" 탭에 나타납니다.
- 모든 시간 기준은 KST입니다.

## 완료/히스토리
- 처음 열 때 SQLD·학은제 체크가 **모두 초기화(미완료)**됩니다(1회성).
- "완료" 탭은 **실제 완료한 날짜 기준**으로 학습 이력을 기록합니다. 이후 체크하는 항목은 체크한 날짜로 남습니다.
